# Статика шапки

Файлы, которые отдаёт Django напрямую (не через Vite).

| Файл | Назначение | Требования |
|---|---|---|
| `logo-emblem.png` | главная эмблема: три таксы и лента | от 1000 px по большей стороне |
| `logo-emblem-small.png` | упрощённый вариант для малых размеров | 256 px, без ленты и мелкой прорисовки |
| `favicon.ico` | иконка вкладки | 32×32 и 16×16 |

Три собаки на эмблеме — три типа шерсти: гладкая, жесткошёрстная,
длинношёрстная. Это наше измерение `coat`, при переделке логотипа
смысл лучше сохранить.

Малый вариант подключается в `templates/base.html` через `<picture>`:
достаточно раскомментировать `<source>`, разметка под него уже готова.
